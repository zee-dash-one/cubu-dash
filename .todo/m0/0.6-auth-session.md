# 0.6 · AuthPort + LocalGuestAuth + DevAdminAuth + Session + `studio` feature tag

Status: todo
Depends on: 0.4

## Goal
Identity behind a Port; dev-only tooling gated by an export feature tag, not a hardcoded bool.

## Context
- `autoload/GameManager.gd`: `const IS_DEV_BUILD: bool = true`; used in `go_dev_lab()` and `scenes/app/main_menu.gd` (Debugger button).
- No `export_presets.cfg` in the repo today.
- Spec §3 (AuthPort, Session, adapters).

## Scope
- `auth/session.gd` `{user_id, display_name, is_guest, provider: local|poki|crazygames|backend, roles[], linked_ids{}}`.
- `auth/auth_port.gd`: `current_session()`, `sign_in_guest(display_name)`, `sign_in(provider, payload)`, `sign_out()`, `get_token()`, `is_admin()`.
- `auth/local_guest_auth.gd`: UUID stored in `PlayerState.profile`, silent guest on first boot (no login screen).
- `auth/dev_admin_auth.gd`: decorator adding role `admin`, only constructed when `OS.has_feature("studio")`. Not security.
- `auth/auth_factory.gd`, `autoload/Session.gd` facade; wire Router `requires_admin` guard.
- Display name validator: 3–16 chars `[A-Za-z0-9_.]` + profanity filter hook (small list in a data file).
- Replace `IS_DEV_BUILD` with `OS.has_feature("studio")` via one helper (e.g. `BuildFlags.is_studio()`).
- `export_presets.cfg`: presets `Web (dev)` with custom feature `studio`, `Web (release)` excluding `res://studio/*`. No signing keys/passwords in the file. Approved by Hil (27/10); Gandalf decides the details. Android/keystore signing values, if ever needed, come from environment variables (`GODOT_ANDROID_KEYSTORE_RELEASE_PATH`, etc.) or Godot's local `.godot/export_credentials.cfg` (already ignored via `.godot/`), never from the committed file.

## Out of scope
Poki/CrazyGames adapters, any backend (D1), login UI (1.2).

## Acceptance criteria
- [ ] Boot creates a guest session with no UI prompt.
- [ ] Without the `studio` feature the Debugger button and dev lab are unavailable.
- [ ] Running from the editor with the `studio` tag (Project Settings → feature override or dev preset) shows them.
- [ ] No email/Google/Facebook login code paths anywhere (Poki rule).
- [ ] `export_presets.cfg` contains no credentials.

## Minimal tests
Guest id persists across reload (in-memory SavePort), name validator cases, `is_admin` false without studio, true with DevAdminAuth.

## Hypotheses
None (D1 decided: no backend yet).
