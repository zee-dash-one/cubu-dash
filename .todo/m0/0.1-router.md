## Goal
Central navigation: route ids, params, back stack and guards. `GameManager.go_*` becomes thin wrappers.

## Context (current files)
- `autoload/GameManager.gd`: `SCENE_*` constants, `change_scene(path)` (= `change_scene_to_file` + `EventBus.scene_changed`), `go_main_menu`, `go_control_settings`, `go_level_select`, `go_dev_lab`, `open_under_construction`, globals `current_world`, `current_phase`, `is_dev_lab_run`, `pending_screen_title`, `const IS_DEV_BUILD := true`.
- `autoload/EventBus.gd`: `scene_changed(path)` (listened by `InputManager`).
- `project.godot` `[autoload]` order: EventBus, AudioManager, GameManager, PlayerStats, SaveLoad, InputManager.
- Callers: `scenes/app/main_menu.gd`, `scenes/select/level_select.gd`, `scenes/run/game.gd`, `scenes/run/pause_menu.gd`, `scenes/app/under_construction.gd`, `scenes/app/control_settings.gd`.

## Scope
- `router/route_table.gd` (route_id → scene path; only routes that exist today: `title` (MainMenu), `select`, `run`, `controls`, `under_construction`; reserve ids for the spec's other routes as comments only).
- `autoload/Router.gd`: `go(route_id, params := {})`, `back()`, `current_route()`, `current_params()`, `can_go_back()`.
- Guards: `requires_feature(name)` via `OS.has_feature`; `requires_admin` as a stub that returns false until 0.6 (`Session` will plug in).
- Emits `EventBus.scene_changed(path)` exactly once per navigation.
- Register `Router` in `project.godot` after `EventBus`, before `GameManager`.
- `GameManager.change_scene` / `go_*` delegate to `Router`; `pending_screen_title` passes as a param to `under_construction`.

## Out of scope
New screens, Studio routes, removing `IS_DEV_BUILD` (0.6), run params (0.5).

## Implementation notes
- Keep the route table as data (Dictionary const), not a `match`.
- Unknown route → `push_error` + no navigation (never crash).
- Back stack: `go` pushes; `back()` pops; going to `title` clears the stack.

## Acceptance criteria
- [ ] All existing flows work unchanged by hand (menu, select, run, pause→menu, controls, under construction, dev lab).
- [ ] No caller uses `change_scene_to_file` directly except `Router`.
- [ ] `back()` on an empty stack is a no-op with a warning.
- [ ] Guarded route refused when feature is missing.

## Minimal tests (GUT, `tests/router/test_router.gd`)
Route resolution, unknown route, push/pop stack, params round-trip, guard refusal (scene change injected via a callable so tests don't load scenes).
