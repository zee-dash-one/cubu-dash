# 0.3 · ContentPort + BundledJsonContent + LevelSelect from data

Status: todo
Depends on: 0.2

## Goal
Worlds and phases come from `res://content/*.json` through a Port, not from code. Also align the transition duration.

## Context
- `scenes/select/level_select.gd`: `_build_world_data()` hardcodes 4 worlds (NEON CUBES, PIXEL PEAKS, VOLT VALLEY, CANDY CORE) × 4 phases "PHASE w-p"; only world 1 / phase 1 unlocked; confirm writes `GameManager.current_world/phase` and opens `Game.tscn`.
- Same file: `const TRANSITION_MS: float = 0.35` (line ~26, value is seconds despite the name), `@export var transition_duration: float = TRANSITION_MS`, comment `# Circle transitions (400ms, ease-in)` (line ~634).
- `RULES.md` "Circle transitions": "**800 ms**".

## Scope
- `content/content_port.gd` (base): `get_worlds()`, `get_world(id)`, `get_phase(id)`, `get_story_beat(id)`, `list(kind)`, `upsert`, `remove`, `validate_all()`.
- `content/bundled_json_content.gd` (read-only; `upsert/remove` return an error).
- `content/content_factory.gd`: `make_default()`.
- `autoload/ContentRepository.gd`: facade with cache; runs `validate_all()` at boot when `OS.is_debug_build()` and logs errors.
- Data: `content/worlds.json`, `content/phases.json` with **exactly** the current 4×4, names and lock state (unlock_rule: world 1 / phase 1 `always`, others `clear_phase` of the previous).
- `level_select.gd` reads worlds/phases from `ContentRepository`; visuals and behaviour identical.
- **Transition (DECIDED 0.35 s):** rename to `TRANSITION_SECONDS := 0.35` as the single source; fix the 400 ms comment; update `RULES.md` "Circle transitions" from 800 ms to 0.35 s (350 ms).

## Out of scope
Actually enforcing unlock rules from save (M1 1.3), story/achievement data files.

## Acceptance criteria
- [ ] `_build_world_data()` removed; select screen looks and behaves the same.
- [ ] Changing a world name in JSON changes it in-game without code edits.
- [ ] `validate_all()` returns empty for shipped content.
- [ ] Only one transition constant; `RULES.md`, comment and code all say 0.35 s.

## Minimal tests
Load bundled content (16 phases, 4 worlds, order preserved), get by id, missing id → null, invalid JSON fixture → validation errors, `upsert` on bundled adapter refused.
